# PENABUR Combat character art

The project owner supplied these Ali and Elton PNGs and confirmed permission to publish their likenesses for this game on 2026-10-21. This records that statement for this project; it does not grant a general reuse license or permission to use an organization's logo. No employee photographs are used as textures.

The PNGs are byte-identical to the supplied consented integration package. Adjacent SHA-256 files and automated tests verify that provenance. Both atlases are 1600×1080 RGBA with eight 400×540 rectangles and foot-aligned pivots. The full source rectangles are retained.

Active clips intentionally use the most stable idle (`idle-0`) and a curated walk (`walk-0, walk-1, walk-2, walk-1`). Ali's large crouch and the extended-arm fourth walk pose are excluded from active loops. The three walk key poses still contain equipment/hand differences and do not represent final rigged animation. No pixels are stretched, recolored or redrawn.

HD coverage is idle/walk only. Jump/fall, guard, light attacks, heavy, skill, ultimate, hurt, KO and victory retain the original geometric animation. See `docs/PHASE2_INTEGRATION.md` for the visual review and limitations. The game is independent and is not an official BPK PENABUR product; no official logo is included.
